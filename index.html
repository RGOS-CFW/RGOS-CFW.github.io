RG OS

An open source Linux emulation distribution for retro handhelds, built on Debian with the ROCKNIX kernel and Device Trees.

DownloadFeatures

#Features

Python launcher

A pygame frontend with artwork, animated menus and shuffled launcher music.

RetroArch cores

25 systems with sensible default cores, plus standalone emulators.

In-game menu

Tap Menu mid-game to resume, restart, save state, load state or exit.

Core Installer

Download missing libretro cores to the ROMS card without reflashing.

Wi-Fi, Bluetooth, SSH

Networking, pairing and remote access built in.

Offline updates

Drop an update tar in update/ on the ROMS card and reboot.

#Download

Write RG OS to an SD card with any image flashing tool, insert it into your handheld and power on. First boot sets everything up.

#Install

  1. Flash the image (or installer image) for your device to an SD card.
  2. Insert the card and power on. An installer image shows Install and Power off; nothing is touched until you choose Install.
  3. The ROMS partition is created (exFAT by default, FAT32 or ext4 optional) and the folder tree is set up.
  4. Copy ROMs to roms/<system>, BIOS files to bios/, music to music/.
  5. Update later by placing an update tar in update/ and rebooting.
