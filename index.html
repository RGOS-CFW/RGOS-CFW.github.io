A Debian-based OS for your retro handheld.

RG OS is an open source Linux emulation distribution for Anbernic handhelds, built on Debian with the ROCKNIX kernel and device trees. Flash a card, copy your ROMs, play.

What you get

Ready for ROMs

First boot creates a ROMS partition on the rest of your card. Choose FAT32, exFAT or ext4 with the installer image.

Updates without reflashing

Drop an update .tar into the update/ folder. Your games, saves and BIOS files are never touched.

Cores and ports

Install extra cores from Tools > Core Installer, and run Linux ports through PortMaster.

Your look

Change the theme, launcher, startup splash and game artwork from Settings.

Wi-Fi and file transfer

Connect to Wi-Fi to copy files over the network and download artwork and cores.

Open source

RG OS code is MIT licensed. Third-party parts keep their own licenses. No games or BIOS files are included.

Get started

You need a supported console, a microSD card (16 GB or more), and a flashing tool such as balenaEtcher or Raspberry Pi Imager.

  1. Pick your imageUse <device>-rgos.img for your console, for example rg35xxh-rgos.img. The installer image (*-rgos-installer.img) sets up the card for you on first boot.
  2. Flash the whole cardDecompress .img.gz first, flash to the card itself (not a partition), then eject it cleanly. This erases the card.
  3. Boot your consoleInsert the card and power on. RG OS creates the ROMS partition and copies PortMaster on first boot. RG Rotate owners flash the SPL once beforehand.
  4. Add gamesCopy ROMs into roms/gba/, roms/snes/, roms/psx/ and so on. Press X in the launcher to rescan.

FAQ

My H700 console shows a black screen.

It is almost always the wrong RAM type (DDR4 vs DDR3) or panel revision. Try the other RAM type, then the alternate panel device tree.

A game starts and then closes.

Check rgos-retroarch.txt (or rgos-native.txt for ports) on the boot partition. A missing BIOS is a common cause.

A system is missing from the menu.

Its core is not installed. Install it from Tools > Core Installer, or supply the core yourself.

The buttons feel reversed.

Use Settings > Swap A / B buttons, or Settings > Map buttons.

Do updates delete my saves?

No. Updates only replace system files on the boot partition.

What is the default SSH password?

rgos. Change it, or switch SSH off, in the networking settings.
