RG OS

An open source Linux emulation distribution for retro handhelds, built on Debian with the ROCKNIX kernel and Device Trees.

DownloadFeatures

#Features

Three launchers

RG OS, RG XMB or RG Classic, with themes, cover art and shuffled music.

27 systems

RetroArch cores for each, including Sega Saturn and PICO-8, plus a Core Installer for more.

In-game menu

Tap Menu to resume, restart, save, load or exit. Menu + Select maps the D-pad to the stick.

Ports and PortMaster

Native Linux ports run from roms/ports, with PortMaster preinstalled.

Wi-Fi, Bluetooth, SSH

Networking, controller pairing and file transfer built in.

Offline updates

Drop an update tar in update/ and reboot. Your games and saves are never touched.

#Download

Write RG OS to an SD card with any image flashing tool, insert it into your handheld and power on. First boot sets everything up.

Compare in a table
Device Argument SoC Base image Partitions
Anbernic RG34XXSP rg34xxsp Allwinner H700 ROCKNIX-H700 (DDR4) MBR
Anbernic RG35XX H rg35xxh Allwinner H700 ROCKNIX-H700 (DDR4) MBR
Anbernic RG35XX SP rg35xxsp Allwinner H700 ROCKNIX-H700 (DDR4) MBR
Anbernic RG Rotate rg-rotate Unisoc T618 ROCKNIX-T618 GPT (uboot)
MiniLoong Pocket 1 miniloong Rockchip RK3566 AURKNIX-RK3566 (Specific) MBR
Always download RG OS from the official project page or trusted mirrors.

The three H700 consoles boot a U-Boot built for one RAM type: use the DDR4 image unless you know yours is DDR3, because a wrong choice gives a black screen. The RG Rotate needs its SPL flashed once before first boot. The MiniLoong Pocket 1 (RK3566) boots straight from the card: no SPL to flash, no RAM choice, and it has a single analog stick.
