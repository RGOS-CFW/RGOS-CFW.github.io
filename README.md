This is the main website for RG OS. Feel free to create a PR and contribute.


## Changelog

`docs/changelog.html` is generated automatically from the commits in
[RGOS-CFW/RGOS](https://github.com/RGOS-CFW/RGOS) by `scripts/update-changelog.mjs`,
run by `.github/workflows/update-changelog.yml` every 30 minutes. Don't edit the
section between the `COMMITS:START` / `COMMITS:END` markers by hand.
