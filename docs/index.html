RG OS documentation

RG OS is a Debian-based emulation distribution for Anbernic handhelds and the MiniLoong Pocket 1 (RG34XXSP, RG35XX H, RG35XX SP, RG Rotate and Pocket 1), built on the ROCKNIX kernel and device trees.

Conventions used in these docs

  • ROMS is the large exFAT partition on the card (/media/roms on the device). Boot partition is the small FAT partition labelled RGOS (/boot on the device).
  • Button names follow the RG OS Gamepad layout: A bottom, B right, X left, Y top. If A and B feel swapped, see Swap A / B buttons in SETTINGS.md.
  • Menu is the hub's Mode button.
  • Device ids used in commands: rg34xxsp, rg35xxh, rg35xxsp, rg-rotate, miniloong.
