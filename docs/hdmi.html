Mini-HDMI output (H700)

RG OS supports mini-HDMI output on the Anbernic RG34XXSP, RG35XX H and RG35XX SP, all based on the Allwinner H700.

The implementation uses the kernel DRM connector (HDMI-A-1) and the existing framebuffer. It does not require a desktop compositor.

Connect and boot

  1. Power the handheld off.
  2. Connect it to the TV or monitor with a mini-HDMI cable before powering on.
  3. Select the correct HDMI input on the TV, then power on the handheld.

When HDMI is detected during boot, the kernel configures the framebuffer for the external display and the RG OS menu scales to it. RetroArch uses the HDMI display's current mode and HDMI audio while the HDMI connector is active.

If no HDMI cable is connected at boot, RG OS uses the built-in screen as usual.

Important: HDMI is selected at boot. Inserting or removing the cable after startup does not live-switch displays. Power off before connecting or disconnecting, then boot again.

Resolution modes

The default resolution cap is 720p, which avoids the additional CPU cost of drawing the menu at 1080p. The saved setting is /var/lib/rgos/display.json:

{"hdmi": "720p"}
ModeOutput modeNotes
720p1280 × 720 at 60 HzDefault; recommended
1080p1920 × 1080 at 60 HzHigher load for the H700's CPU-drawn menu
480p720 × 480 at 60 HzLower-resolution fallback
autoTV preferred modeRemoves the RG OS resolution cap

Change the mode over SSH

Connect to the handheld over SSH as root and inspect the current HDMI status:

python3 /opt/rgos/hdmictl.py status

Set a mode with:

python3 /opt/rgos/hdmictl.py set 720p

Replace 720p with 480p, 1080p or auto. A successful change to the boot configuration requires a restart, with the TV connected before powering on.

The tool updates the APPEND lines in /boot/extlinux/extlinux.conf, creates a one-time backup named extlinux.conf.pre-hdmi, and stores the selected mode in /var/lib/rgos/display.json. The saved choice is reapplied during startup if an OS update replaces the boot configuration.

If extlinux.conf is missing or has no APPEND line, the tool reports a failure and saves nothing, rather than claiming the mode was applied.

Inspect the status or reapply the saved setting with:

python3 /opt/rgos/hdmictl.py status
python3 /opt/rgos/hdmictl.py boot

Audio and RetroArch

When the kernel reports HDMI as connected and enabled, RG OS selects the HDMI ALSA playback device for RetroArch. Otherwise, RetroArch uses the handheld's built-in audio device.

While HDMI is active, RetroArch is directed to the HDMI connector and uses its current display mode rather than forcing the handheld panel's fixed dimensions.

Troubleshooting

  • TV says no signal: Power off, connect the cable firmly at both ends, select the TV's correct HDMI input, then power on the handheld.
  • No HDMI connector is detected: Run python3 /opt/rgos/hdmictl.py status. The kernel must expose an HDMI connector under /sys/class/drm.
  • Black screen or unsupported mode: With the handheld display connected as usual, SSH in and run python3 /opt/rgos/hdmictl.py set 720p. Reboot with the TV connected. If needed, try 480p.
  • No sound over HDMI: Connect the TV before boot and inspect python3 /opt/rgos/hdmictl.py status for the HDMI audio device.
  • Built-in screen works but TV does not: Confirm that the device is one of the supported H700 handhelds and that the TV and cable accept the selected mode.

Device limitation: The RG Rotate (T618) is not included in this H700 mini-HDMI implementation.
