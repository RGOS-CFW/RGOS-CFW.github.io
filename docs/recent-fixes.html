Recent fixes

A short record of the recent launch, core-configuration and networking fixes. See the linked system guides for setup details.

Nintendo 64

The Mupen64Plus-Next launch profile now uses a supported 16:9 render-size preset (640x360) alongside the 4:3 320x240 preset. The profile keeps GLideN64, HLE RSP, the dynamic recompiler and conservative GLES-friendly graphics options. A failed first launch can retry with the cached interpreter. See Nintendo 64.

Sega Saturn

Saturn settings are separated by core. YabaSanshiro uses its own SH-2 dynarec, frameskip and original-resolution defaults; Yabause has its own frameskip/thread settings; Beetle Saturn remains on its software-rendered path. BIOS detection distinguishes the optional YabaSanshiro/Yabause BIOS from Beetle's regional BIOS files. See Saturn and BIOS files.

PICO-8

Both .p8 and .p8.png carts are recognized. PNG-cart display names and artwork stems drop both extensions, and the launcher has a fallback core order of fake-08 then retro8. See PICO-8.

Wi-Fi and DHCP

The DHCP hook uses Unix line endings so the POSIX shell can parse its case statement. Lease handling flushes stale routes before adding the new address and default route; DNS uses lease-provided servers, or falls back to the router followed by 1.1.1.1 and 9.9.9.9 when the lease has no DNS option. See Wi-Fi.

Dreamcast standalone Flycast

RG OS detects a standalone flycast executable separately from libretro cores, launches it directly, persists its XDG config/data on the ROMS card, and links the shared Dreamcast BIOS directory when appropriate. It is not downloaded by Core Installer. See Dreamcast.

Diagnostics

For RetroArch systems, include rgos-retroarch.txt from the boot partition. For standalone Flycast, include rgos-native.txt. A log from one system should not be used as proof of the cause of another system's launch failure. See Logs and diagnostic files.
