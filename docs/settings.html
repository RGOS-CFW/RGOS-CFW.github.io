Settings reference

Open Settings from the home screen. Rows, in order:

Setting What it does
Theme Colour scheme. See LAUNCHERS-AND-THEMES.md
Launcher RG OS, RG XMB or RG Classic
Startup splash On, video only or off; X previews
Emulators Pick the RetroArch core used for each system (SYSTEMS.md)
Missing BIOS check Lists missing BIOS files and where they go (BIOS.md)
Game artwork SteamGridDB key, download missing artwork, show or hide covers (ARTWORK.md)
Map buttons Teach RG OS which physical button is which, for when buttons are wrong
Swap A / B buttons Toggle with A. Applies to the launcher, RetroArch and native ports
DPAD to joystick Toggle with A. While a game runs, D-pad presses move the left stick instead (for N64, PSP, PlayStation and other games that read the stick). Menu + Select in a game turns it on, holding Menu + Select turns it off (IN-GAME-MENU.md)
Wi-Fi Scan, connect, hidden networks (NETWORKING.md)
Bluetooth Pair controllers, keyboards and headsets
SSH / file transfer Turn the SSH/SFTP server on or off
Information Build, kernel, storage, battery, brightness, volume and input status

Favourites, artwork and your key file live on the ROMS card (SD-CARD-LAYOUT.md).

File Manager (Tools)

Browse, copy, cut, paste, rename and delete files on the SD cards. Pasting into a folder that already holds the same name creates a (copy) name instead of overwriting. Use it for small jobs; for bulk copying use a PC or SFTP.

Power

Power Off in the home screen, or hold Select + Start from the launcher.
