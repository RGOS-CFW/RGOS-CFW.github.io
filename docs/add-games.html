Add games

On this pageQuick startWhere games goFolders and file typesWays to copyDisc gamesBIOSNot showing up

RG OS does not come with games. You add your own ROMs and disc images by copying them into one folder per system on the ROMS partition, then rescanning in the launcher.

RG OS does not provide games or BIOS files. Only copy games and BIOS files you are legally allowed to use.

Quick start

  1. Put the card in your PC and open the large ROMS partition (not the small RGOS one).
  2. Open the roms folder and copy each game into the folder for its system, for example roms/gba/ or roms/psx/.
  3. Eject the card, put it back in the console and power on.
  4. In the launcher press X to rescan. Your games appear under their systems.

Where games go

The ROMS partition (/media/roms on the device) holds everything you own. Games go under roms/, with one folder per system: 

ROMS/
  roms/
    gba/        Game Boy Advance games
    snes/       SNES games
    psx/        PlayStation discs
    ports/      native ports and PortMaster
    ...
  bios/         BIOS files (see below)
  saves/        in-game saves, created on first launch
  states/       save states, created on first launch
  artwork/      cover art

saves/, states/, bios/ and screenshots/ are created when a game is first launched, so you do not need to make them. The whole layout is in SD card layout.

Use the exact folder names from the table below. A game in a folder the launcher does not know about is never listed.

Ways to copy games

MethodGood forHow
Card reader on a PC Big libraries, first setup Copy into roms/<system>/ on the ROMS partition. Eject cleanly afterwards.
SFTP over Wi-Fi Adding games without taking the card out Set up Wi-Fi, turn on Settings > SSH / file transfer, then connect with any SFTP client (WinSCP, FileZilla, sftp) and copy into /media/roms/roms/<system>/. See Wi-Fi, Bluetooth and SSH.
File Manager on the console Small jobs: moving or renaming a few files Tools > File Manager can browse, copy, cut, paste, rename and delete. For bulk copying use a PC or SFTP.
The default SFTP password is rgos. Change it, and turn SSH off again when you are done, because anyone on your network can use it while it is on.

Rescan

Press X in a game list or on the home screens to rescan after adding or removing games. A system with no games and no installed core is hidden; a system with a core installed still shows up with no games in it.

Disc-based games

  • Prefer .chd over a pile of .bin and .cue files; it is one file per disc.
  • .cue plus .bin: keep the .bin track files next to the .cue. Only the disc file is listed, not the tracks.
  • Multi-disc games: use an .m3u playlist for PlayStation, Sega CD and GameCube, and keep the playlist next to the disc images. Saturn and Dreamcast also take .m3u for multi-disc games.
  • Dreamcast: one folder per game is fine. Keep a .gdi file's track files next to it.
  • Neo Geo: leave ROM sets zipped (.zip or .7z), and put neogeo.zip in bios/, also zipped.

Things that trip people up

  • .bin is shared by Genesis, 32X, Pico and the Atari systems. Keep each system's files in its own folder.
  • .iso is shared by Sega CD, PlayStation and GameCube. Wii is not supported; keep Wii dumps out of roms/gc.
  • GameCube is RG Rotate only. The system is hidden on every other device. See GameCube.
  • Arcade and Neo Geo only appear once a FinalBurn Neo core is present; RG OS does not ship one. You can add it with Tools > Core Installer or by putting an aarch64 fbneo_libretro.so in cores/.
  • PICO-8 carts are .p8 or .p8.png files; a plain cover .png is not a cartridge.
  • Heavy systems (N64, Saturn, Dreamcast) will not run every game at full speed on the H700 consoles. Many N64 games need the right stick; on a console without sticks, turn on DPAD to joystick.

BIOS files

Some systems need BIOS files, which RG OS does not ship. Put yours in bios/ on the ROMS partition. Then open Settings > Missing BIOS check: it lists what is missing, where each file goes, and warns when a checksum differs from the expected one. See BIOS files.

After adding games

  • Favourites: press Y on a game to add or remove it (Launchers, themes, splash and music).
  • Cover art: Settings > Game artwork downloads missing covers from SteamGridDB (Game artwork).
  • A different core: Settings > Emulators lists the installed cores compatible with each system, and Tools > Core Installer downloads more (Core Installer).
  • Controls in game: Controls and hotkeys.

A game does not show up

CheckWhy
Did you press X to rescan?The launcher does not pick up new files until it rescans.
Is the folder name exactly as in the table?For example genesis, not megadrive, and psx, not ps1.
Is the file type listed for that system?Other extensions are not offered as games.
Is the game on the ROMS partition, inside roms/?The small RGOS boot partition is not scanned for games.
Does the name start with a .?Those files are ignored.
Is a core installed for the system?Systems without a compatible core are hidden. Check Settings > Emulators or Tools > Core Installer.
Is it a GameCube game on a console other than the RG Rotate?GameCube is hidden on every other device.

If a game is listed but will not start, see Troubleshooting and Logs and diagnostic files.
